## Setup (each VM)

```powershell
. .\spikes\vm\vm.ps1
. .\docs\spikes\phase3-vm-check\helpers.ps1
# $vm, $u, $data as phase3-vm-check/protocol.md "Setup" sets them (VM-C's user name as code points).
Start-CleanVm $vm $u -Type separate
Install-Phase3App $vm $u $artifact
$repo = (Resolve-Path .).Path   # whole paths: VBoxManage's working folder is not PowerShell's location
Copy-ToGuest $vm @("$repo\spikes\vm\guest") 'C:\cmdstudio\spikes\vm\' $u      # not spikes\vm whole: tmp\ holds the host's screenshots
Copy-ToGuest $vm @("$repo\spikes\recovery") 'C:\cmdstudio\spikes\' $u
Copy-ToGuest $vm @('<scratchpad>\crash-dll\clink_dll_x64.dll') 'C:\cmdstudio\crash-dll\' $u
Copy-ToGuest $vm @('<scratchpad>\vmrun\fake\cmd.exe') 'C:\cmdstudio\fake\' $u
Copy-ToGuest $vm @('<scratchpad>\hang\oh-my-posh.exe') 'C:\cmdstudio\hang\' $u
$g = 'C:\cmdstudio\spikes\vm\guest'
$dataArg = '-Data (Join-Path $env:LOCALAPPDATA ''ai.resincore.cmdstudio'')'   # read in the guest's own session
$startApp = { Send-Run $vm 'wscript.exe //B //Nologo C:\cmdstudio\phase3\check\start-app.vbs'; Start-Sleep -Seconds 10 }
$closeApp = { Invoke-GuestPs $vm 'Get-Process cmdstudio -ErrorAction SilentlyContinue | ForEach-Object { [void]$_.CloseMainWindow() }' $u | Out-Null; Start-Sleep -Seconds 5 }
$closeCmd = { Invoke-GuestPs $vm 'Get-Process cmd -ErrorAction SilentlyContinue | Stop-Process -Force' $u | Out-Null }
$health = { Invoke-GuestPs $vm "if (Test-Path -LiteralPath '$data\health') { `$f = @(Get-ChildItem -Force -LiteralPath '$data\health'); if (`$f.Count) { `$f | ForEach-Object { `$_.Name + ' = ' + (Get-Content -Raw -LiteralPath `$_.FullName).Trim() } } else { '(health folder exists, empty)' } } else { '(no health folder)' }" $u }
$appLog = { Invoke-GuestPs $vm "Select-String -LiteralPath '$data\logs\cmdstudio.log' -Pattern 'crash_check|pause reason|resume by|cmd=recovery_status' | ForEach-Object Line; '--- the last 6 lines'; Get-Content -Tail 6 -Encoding UTF8 -LiteralPath '$data\logs\cmdstudio.log'" $u }
$started = { Invoke-GuestPs $vm "Get-Process cmdstudio -ErrorAction SilentlyContinue | Select-Object -First 1 | ForEach-Object { 'cmdstudio.exe started (UTC): ' + `$_.StartTime.ToUniversalTime().ToString('o') }" $u }
```

`& $health` lists `health\` with each file's text, and says `(health folder exists, empty)` when it holds nothing: "no tag" below means that line, or a listing without a `start-…`. `& $appLog` prints every line of the app's log that belongs to the start's crash check, a pause, a resume or Home's `recovery_status` call (each line starts with its UTC time), then the last six lines for context: a start's lines fall out of a plain tail once Home and Help have logged their commands. It prints every matching line of the whole log, the earlier steps' included, so read the newest stamp: the last matching line of each kind is the run under test. `Invoke-GuestPs` sends its command encoded, so `$data` may hold Thai; `Invoke-GuestDesktop`'s arguments may not, hence `$dataArg`. `Invoke-GuestDesktop` runs a guest script on the user's desktop, where `-Data`'s default is the user's own data folder, so the VM-A-only steps pass no `-Data`.
