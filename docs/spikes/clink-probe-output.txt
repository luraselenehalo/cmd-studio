== G16: clink.autoupdate
        Name: clink.autoupdate
 Description: Auto-update the Clink program files
     Options: off,check,prompt,auto
       Value: check
     Default: check

When 'off', Clink does not automatically check for updates, but you can
use 'clink update' to check for updates.
When 'check' (the default), Clink periodically checks for updates and
prints a message when an update is available.
When 'prompt', Clink periodically checks for updates and if one is
available then it shows a window to prompt whether to install the update.
When 'auto', Clink periodically checks for updates and also
attempts to automatically install an update.  If elevation is needed then
it pops up a prompt window, otherwise it automatically installs the update.
Setting 'clink.autoupdate' set to 'off'.
exit=0
