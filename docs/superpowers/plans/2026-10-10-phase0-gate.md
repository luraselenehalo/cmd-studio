# Phase 0 — Gate and Spikes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn every ⬜ item in spec §0 into ✅ with recorded evidence, or into a spec change, and set up the toolchain, public repo and test machines that later phases need.

**Architecture:** Throwaway probes live under `spikes/` and are never shipped. Each probe writes a short evidence report to `docs/spikes/`. Steps marked 👤 need the founder (approval, a click, or a machine only they control). Nothing in this plan edits the founder's live AutoRun, and nothing drives GUI windows on the founder's machine. Windows Terminal settings are edited only in Task 6, with a backup restored in the same step.

**Tech Stack:** PowerShell 5.1, Rust (spike crates only), Clink 1.9.34 from the prototype folder, Oh My Posh 31.5.0 (already installed), GitHub Actions `windows-latest` once the repo is public.

**Spec:** `docs/superpowers/specs/2026-10-10-cmd-studio-design.md`

## Global Constraints

- App identifier `ai.resincore.cmdstudio`; repo name `cmd-studio`; license MIT.
- Never automate GUI windows (focus, keystrokes, moving) on the founder's machine (spec §2.2 #7). Use hidden windows, VMs, or CI.
- Shells started by the Claude desktop app are MSIX-virtualized. Their writes to `HKCU` and to `%LOCALAPPDATA%` outside `Packages` are invisible to other programs, so they prove nothing about real behavior (spec §2.2 #1). Real-system checks run on CI, on VMs, or through `wt -w new cmd /c <command>`.
- A gate item becomes ✅ only when its report has the exact command and its actual output. Record unexpected results as they are. Change the spec to match reality; never adjust the evidence.
- Every report states where it ran: dev machine (AtlasOS, not representative), CI runner (Windows Server), or a named VM.
- Prototype binaries: `%USERPROFILE%\cmd-claude-theme\clink-bin\clink_x64.exe` (Clink 1.9.34) and the `oh-my-posh` command (31.5.0, winget MSIX).
- Commits: English message written to `.git/CMDSTUDIO_COMMIT_MSG` with the Write tool, then `git commit -F .git/CMDSTUDIO_COMMIT_MSG`. No Claude attribution lines of any kind. Follow the `auroraz-pr-workflow` skill before every commit, push or PR.

## Review Focus

1. A probe run from the Claude app's shell can "pass" only inside the virtualized view. Every conclusion about the registry or AppData must cite CI, a VM, or `wt`.
2. The dev machine (AtlasOS) is not stock Windows. G7, G8, G12 and G13 each need one run on stock Windows before they become ✅ (Task 8 reruns them).
3. Thai-language Windows may print a different cmd header and Thai text in a different code page. G4 and G17 must also run on the Thai VM before ✅.
4. A Clink probe in a hidden console may not inject at all. An empty probe log is "inconclusive", not "fails". Rerun it on a VM before deciding.
5. Web facts change (SignPath terms, licenses, Store IDs). Reports must quote the page text and the date it was fetched.

`spikes/jsonc-cst/src/lib.rs`:
```rust
#[cfg(test)]
mod tests {
    use jsonc_parser::cst::CstRootNode;
    use jsonc_parser::{json, ParseOptions};

    const FIXTURE: &str = include_str!("../fixtures/settings.jsonc");
    const CMD_GUID: &str = "{0caa0dad-35be-5f56-a8ff-afceeeaa6101}";

    #[test]
    fn edits_keep_comments_and_other_bytes() {
        let root = CstRootNode::parse(FIXTURE, &ParseOptions::default()).expect("fixture parses");
        let obj = root.object_value_or_set();

        // 1. Add our scheme.
        let schemes = obj.array_value_or_set("schemes");
        schemes.append(json!({ "name": "CMD Studio", "background": "#1f1e1d" }));

        // 2. Set keys on the cmd profile, found by guid.
        let list = obj
            .object_value("profiles")
            .and_then(|p| p.array_value("list"))
            .expect("profiles.list exists");
        let cmd = list
            .elements()
            .into_iter()
            .filter_map(|e| e.as_object())
            .find(|o| {
                o.get("guid")
                    .and_then(|p| p.value())
                    .and_then(|v| v.as_string_lit())
                    .map(|s| s.decoded_value().ok().as_deref() == Some(CMD_GUID))
                    .unwrap_or(false)
            })
            .expect("cmd profile exists");
        match cmd.get("colorScheme") {
            Some(prop) => prop.set_value(json!("CMD Studio")),
            None => {
                cmd.append("colorScheme", json!("CMD Studio"));
            }
        }

        let out = root.to_string();
        // Comments survive.
        assert!(out.contains("// User's own comment at the top"));
        assert!(out.contains("// inline comment"));
        assert!(out.contains("/* block comment the user wrote */"));
        // Edits landed.
        assert!(out.contains("\"colorScheme\": \"CMD Studio\""));
        assert!(out.contains("\"name\": \"CMD Studio\""));
        // The PowerShell profile block is byte-identical.
        let ps = "\"name\": \"Windows PowerShell\" // inline comment";
        assert!(out.contains(ps));
        // The result is still valid JSONC.
        jsonc_parser::parse_to_value(&out, &ParseOptions::default()).expect("still parses");
        println!("{out}");
    }
}
```

```powershell
$ErrorActionPreference = 'Stop'
$log = New-Item -ItemType Directory -Force spike-logs
Add-Type -Namespace W -Name Font -MemberDefinition @'
[DllImport("gdi32.dll", CharSet = CharSet.Unicode)] public static extern int AddFontResourceW(string f);
[DllImport("gdi32.dll", CharSet = CharSet.Unicode)] public static extern bool RemoveFontResourceW(string f);
[DllImport("user32.dll")] public static extern IntPtr SendMessageTimeoutW(IntPtr h, uint m, UIntPtr w, IntPtr l, uint flags, uint timeout, out UIntPtr r);
'@
function Broadcast { $r = [UIntPtr]::Zero; [void][W.Font]::SendMessageTimeoutW([IntPtr]0xffff, 0x001D, [UIntPtr]::Zero, [IntPtr]::Zero, 2, 1000, [ref]$r) }
function Has($family) { powershell -NoProfile -Command "Add-Type -AssemblyName System.Drawing; [bool]((New-Object System.Drawing.Text.InstalledFontCollection).Families | Where-Object Name -eq '$family')" }

$zip = Join-Path $env:RUNNER_TEMP 'cascadia.zip'
Invoke-WebRequest 'https://github.com/microsoft/cascadia-code/releases/download/v2407.24/CascadiaCode-2407.24.zip' -OutFile $zip
Expand-Archive $zip (Join-Path $env:RUNNER_TEMP 'cascadia') -Force
$src = Get-ChildItem (Join-Path $env:RUNNER_TEMP 'cascadia') -Recurse -Filter 'CascadiaCode.ttf' | Select-Object -First 1
$fontsDir = Join-Path $env:LOCALAPPDATA 'Microsoft\Windows\Fonts'
New-Item -ItemType Directory -Force $fontsDir | Out-Null
$dst = Join-Path $fontsDir 'CascadiaCode.ttf'
$key = 'HKCU:\Software\Microsoft\Windows NT\CurrentVersion\Fonts'
"before: $(Has 'Cascadia Code')"
Copy-Item $src.FullName $dst -Force
New-ItemProperty -Path $key -Name 'Cascadia Code (TrueType)' -Value $dst -PropertyType String -Force | Out-Null
"add=$([W.Font]::AddFontResourceW($dst))"; Broadcast
"after install: $(Has 'Cascadia Code')"
"remove=$([W.Font]::RemoveFontResourceW($dst))"; Broadcast
Remove-ItemProperty -Path $key -Name 'Cascadia Code (TrueType)'
Remove-Item $dst
"after uninstall: $(Has 'Cascadia Code')"
```

- [ ] **Step 3: Write the AutoRun probe**

`spikes/windows/autorun.ps1`:
```powershell
$ErrorActionPreference = 'Stop'
$key = 'HKCU:\Software\Microsoft\Command Processor'
New-Item -Path $key -Force | Out-Null
$orig = (Get-ItemProperty $key -ErrorAction SilentlyContinue).AutoRun
$dir = Join-Path $env:LOCALAPPDATA 'สปายค์ ทดสอบ & R&D'
New-Item -ItemType Directory -Force $dir | Out-Null
$marker = Join-Path $dir 'marker.log'
$exe = Join-Path $dir 'probe.cmd'
Set-Content $exe "@echo probe ran>>`"$marker`"" -Encoding Ascii
function RunCmd { $p = Start-Process cmd.exe -ArgumentList '/c exit' -NoNewWindow -Wait -PassThru -RedirectStandardError (Join-Path $dir 'err.txt'); "exit=$($p.ExitCode) stderr=[$(Get-Content (Join-Path $dir 'err.txt') -Raw)]" }
try {
  $guard = "if exist `"$exe`" `"$exe`""
  Set-ItemProperty $key AutoRun $guard
  "(a) file present: $(RunCmd) marker=[$(Get-Content $marker -Raw)]"
  Remove-Item $marker -ErrorAction SilentlyContinue
  Rename-Item $exe 'probe.cmd.gone'
  "(b) file missing: $(RunCmd)"
  Rename-Item (Join-Path $dir 'probe.cmd.gone') 'probe.cmd'
  Set-ItemProperty $key AutoRun "echo foreign>>`"$marker`" & $guard"
  "(c) chained: $(RunCmd) marker=[$(Get-Content $marker -Raw)]"
  $clinkZip = Join-Path $env:RUNNER_TEMP 'clink.zip'
  Invoke-WebRequest 'https://github.com/chrisant996/clink/releases/download/v1.9.34/clink.1.9.34.4e8ae4.zip' -OutFile $clinkZip
  Expand-Archive $clinkZip (Join-Path $dir 'clink') -Force
  $cx = Join-Path $dir 'clink\clink_x64.exe'
  $prof = Join-Path $dir 'clink-profile'
  Remove-ItemProperty $key AutoRun -ErrorAction SilentlyContinue
  $base = (Measure-Command { 1..20 | ForEach-Object { cmd /c exit } }).TotalMilliseconds / 20
  Set-ItemProperty $key AutoRun "if exist `"$cx`" `"$cx`" inject --autorun --quiet --profile `"$prof`""
  $with = (Measure-Command { 1..20 | ForEach-Object { cmd /c exit } }).TotalMilliseconds / 20
  "(e) cmd /c average ms: without=$([math]::Round($base,1)) with-clink=$([math]::Round($with,1))"
} finally {
  if ($null -eq $orig) { Remove-ItemProperty $key AutoRun -ErrorAction SilentlyContinue } else { Set-ItemProperty $key AutoRun $orig }
  "AutoRun restored to: [$((Get-ItemProperty $key -ErrorAction SilentlyContinue).AutoRun)]"
}
```
Case (d) of G13 (Thai and spaces in the path) is covered because `$dir` holds Thai letters, a space and `&` in every case above.
